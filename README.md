# Ahmad Mayiludin Portfolio

Portfolio pribadi untuk menampilkan project web, mobile, dashboard operasional,
UI/UX, data, dan Computer Vision milik Ahmad Mayiludin.

## Tech Stack

- Next.js 13
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Resend contact form
- Vercel Analytics

## Featured Project Categories

- CRM Sales Pipeline Dashboard
- Procurement & Vendor Management Dashboard
- Mobile Asset Management App
- HRIS Employee Self-Service Portal
- RestoPOS Admin & Customer App
- Donation Website
- Data Mining and Computer Vision projects

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Build

```bash
npm run build
```
